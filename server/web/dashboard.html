Pairing and migration

Download trust certificate

Install the trust certificate on each phone or remote display once. Then scan a feed’s QR code on the same network.

Trust the certificate
  • iPhone or iPad Open the certificate, install the downloaded profile in Settings, then enable full trust under General → About → Certificate Trust Settings.
  • Android Open Settings and search for “Install CA certificate.” Choose the downloaded file. The exact menu varies by device.
  • Desktop Import the certificate as a trusted root in your operating system or browser.

Settings include feed IDs, viewer links, rotation and camera preferences. An imported LAN address is used if available on this computer.
