# LAN Lens for OBS v0.2.5

## Camera and pairing

- Install LAN Lens Camera on the iPhone or Android home screen. The app can pair directly with the six-character uppercase letter-and-number code shown below the QR.
- Hold on a subject to request one-shot autofocus when the browser supports a focus point. LAN Lens no longer copies a potentially stale autofocus distance into manual mode.
- Selecting Manual focus keeps the lens where it is until you move the Near–Far slider. Focus and exposure can be held independently on supported lenses.
- **Settings → Custom HTTPS certificate** accepts an existing PEM chain and matching private key for a LAN-resolvable DNS hostname. A certificate from an issuer the phones already trust lets them connect without installing a LAN Lens CA.

## OBS controller

- Each feed has a persistent **Resolution** accordion with Auto, 360p, 540p, 720p, and 1080p. The phone shows a five-second warning before applying a host change. Start the phone camera before using this control.

## Installation

Close OBS before running the unsigned Windows x64 MSI. Reopen OBS and choose **Docks → LAN Lens for OBS**. Requires the full OBS Studio 33.x build, version 33.0.1 or later.

Checked in portable Windows OBS with a simulated camera. Physical lens behavior, home-screen installation on physical iOS and Android devices, and a full MSI installation remain unverified.
