# LAN Lens for OBS v0.2.4

## Pairing and camera

- Each pairing dialog shows a short, readable HTTPS link below the QR code. Type the six-character code in either case. Links expire after five minutes and can be used once.
- Refreshing a paired phone tab keeps the selected lens, resolution, zoom, aspect, Eco Mode, and supported focus and exposure settings. A running camera attempts to resume automatically if the browser still has permission. An explicitly stopped camera stays stopped.
- The resolution readout follows the outgoing frame size. Raising the resolution can briefly restart the camera if the browser keeps capturing at the previous size.
- Focus and exposure lock apply independently. LAN Lens checks the values reported by the camera, restores failed changes, and leaves exposure in its previous mode when it cannot safely hold it.

## OBS controller

- Settings uses a gear icon. Identify moved to Feed setup, and Preview moved to Display controls.
- Feed setup, OBS sources and scenes, and Feed controls are collapsible. The controller saves their state across browser and OBS restarts.
- Choose **Link existing OBS source** in Feed setup for a feed without a linked source. Select the vacant source by name to update it in every scene where it is already used. LAN Lens checks that the source is still vacant before changing it.

## Installation

Close OBS before running the unsigned Windows x64 MSI. Reopen OBS and choose **Docks → LAN Lens for OBS**. Requires the full OBS Studio 33.x build, version 33.0.1 or later.

Verified in portable Windows OBS with a simulated camera. Physical camera optics and a full MSI installation remain unverified.
