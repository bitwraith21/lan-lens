# LAN Lens for OBS v0.2.10

- **Open in Browser** now lives under **Settings** in the OBS dock.
- Removed the duplicate OBS statistics panel. OBS's own Stats dock remains available from the OBS Docks menu.
- Feeds with a connected display and no active camera show **Waiting for camera**. Feed cards are sized to their own contents, including when an adjacent card is expanded.
- The phone loads the optional **Camera statistics** code on first open. It processes and displays statistics only while the panel is open.

Close OBS before running the unsigned Windows x64 MSI. Requires the full OBS Studio 33.x build, version 33.0.1 or later.
