# LAN Lens for OBS v0.2.7

## Phone camera

- Portrait now produces a 9:16 frame. Landscape and Landscape cropped produce a 16:9 frame. The preview and receiver use the same framing. When the phone returns the wrong native aspect, LAN Lens crops the upright image to fit without stretching it. The phone shows the selected aspect and output dimensions.
- Removed the focus and exposure lock button and preview tap-to-meter and hold-to-lock gestures. Manual focus, exposure, and compensation remain available on supported lenses.

## Installation and trust

- Android shows an install invitation when Chrome supplies a native install prompt. **Install app** also opens the browser guidance when the prompt is unavailable.
- The phone certificate download page links back to the HTTPS camera using the correct port. The app and download page describe how to check a remaining Chrome certificate warning.

## Windows

Close OBS before running the unsigned Windows x64 MSI. Reopen OBS and choose **Docks → LAN Lens for OBS**. Requires the full OBS Studio 33.x build, version 33.0.1 or later.

Verified with portable OBS and a simulated camera. The Redmi certificate warning and native Android install dialog require verification on the phone.
