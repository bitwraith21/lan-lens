# LAN Lens for OBS v0.2.12

- Fixed the controller microphone button staying disabled when a phone disconnected before confirming a command. The button becomes available as soon as the reconnected phone reports an active microphone.
- The OBS dock and browser controller now follow the phone’s live microphone status, including mute, availability, and temporary interruptions. Updates travel with existing connection checks.
- Improved contrast for the muted microphone button on the phone and controller.
- Added fallbacks for older browsers in connection status, control rendering, and viewport sizing.

Close OBS before running the unsigned Windows x64 MSI. Requires the full OBS Studio 33.x build, version 33.0.1 or later.
