# LAN Lens for OBS v0.2.6

## Phone camera

- Normal capture sends the native camera track directly to WebRTC. Software zoom, center crop, and a resolution cap that the encoder cannot enforce use a separate frame processor only when needed. Auto starts at 540p, watches encoder load and connection quality, and capture runs at up to 24 fps.
- Focus, exposure, zoom, and torch use camera-control constraints separately from resolution. This fixes a conflict that could prevent older Chromium browsers from applying manual focus and lock. Tap the preview to meter exposure where supported. Hold to request an autofocus and exposure lock on compatible lenses.
- The aspect buttons are Portrait, Landscape cropped, and Landscape. The normal highlight follows screen rotation. The crop stays selected until changed. Landscape requests screen rotation on supported browsers and can rotate the app layout when a browser denies orientation lock.
- Android shows **Install camera app** when the browser supplies a native installation action. Otherwise, **Home screen help** explains the browser menu and HTTPS requirements. The iPhone installation instructions remain available.

## Phone certificate setup

- The controller can show a QR and short LAN address to download the built-in CA directly to a phone. Compare the certificate fingerprint against the controller before installing. With a custom HTTPS certificate already trusted by the phones, the download and manual install can be skipped.

## OBS controller

- The Resolution accordion shows frame dimensions reported by connected receivers. This distinguishes the decoded feed size from the size OBS or the browser displays on screen.

## Installation

Close OBS before running the unsigned Windows x64 MSI. Reopen OBS and choose **Docks → LAN Lens for OBS**. Requires the full OBS Studio 33.x build, version 33.0.1 or later.

Verified with portable OBS and a simulated camera. Physical phone performance, lens behavior, native installation and rotation prompts, and full MSI installation remain unverified.
