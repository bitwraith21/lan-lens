# LAN Lens for OBS v0.2.16

- In full-screen landscape, the main camera toolbar sits at the bottom center, and Settings, Exit full screen, Microphone, and Flashlight form a vertical column on the right. Full-screen portrait keeps its two centered rows.
- The Windows installer lists **bitwraith21** as the manufacturer. This MSI is unsigned, so SmartScreen may still display **Unknown publisher**.

Close OBS before running the Windows x64 MSI. Requires the full OBS Studio 33.x build, version 33.0.1 or later.
