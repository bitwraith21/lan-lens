# LAN Lens for OBS v0.2.13

- Scan the OBS pairing QR from inside the installed phone app. Manual pairing remains available under **Use a pairing code instead**. When capture is stopped, **Pair another feed** opens the same two options.
- The lens picker lists the rear and front lenses the phone browser makes available. Double-tap the live preview or use the switch icon beside the picker to move between front and rear. Switching back restores the last selected rear lens.
- Grouped the phone controls into camera actions, lens and framing, stream resolution, and advanced controls.
- Added a full-screen camera view with floating shortcuts and an expandable settings panel.

Close OBS before running the unsigned Windows x64 MSI. Requires the full OBS Studio 33.x build, version 33.0.1 or later.
