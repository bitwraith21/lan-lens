# LAN Lens for OBS v0.2.11

- Added a microphone button beside the phone's flashlight and a separate mute/unmute button under each feed's **Feed controls**. The setting applies to the audio track sent by LAN Lens and persists with the feed.
- The phone reports host microphone changes. The controller gets a confirmation or an error from the phone for mute, unmute, restart, and resolution changes.
- The phone shows a toast when the host renames the feed, unpairs the phone, or deletes the feed. A declined restart request is reported on both screens.

Close OBS before running the unsigned Windows x64 MSI. Requires the full OBS Studio 33.x build, version 33.0.1 or later.
